# pair-wise-yy-61 航空器定检工作包执行与放行审阅平台

支持工卡依赖、测量值容差校验、**可恢复提交队列**、离线暂存、**服务器版本冲突的双方保留与人工合并**、分阶段签字、版本差异和放行锁定。超差项目必须由授权人员处理后才能继续。

## 离线提交与冲突处理

- 所有“完成提交 / 超差授权”统一进入带顺序号的提交队列（`queue`），持久化在 `localStorage`，断网或关闭页面都不丢失。
- 恢复联网（手动切换、浏览器 `online` 事件、重新打开页面）后，重放器严格按序号逐条提交；自己之前的提交成功后，后续项自动变基到新版本，他端提交不会被静默变基。
- 提交命中服务器 409（版本已变化）时：队列立即暂停，**本地版本与服务器版本（含共同基线）同时保留**，执行人员在三向对照弹窗中选择：
  - 合并：可编辑合并后的状态/测量值/发现，确认后基于服务器最新版本重新入队；
  - 放弃本地：以服务器内容为准，本地原值写入审计，绝不悄悄覆盖；
  - 暂不处理：冲突持久化，重新打开页面仍可继续裁决。
- 每笔提交成功后，工作包版本、工卡状态、审计记录在同一笔状态更新中落盘；放行门禁实时联动“未决冲突 / 待同步提交 / 待授权 / 完成率 / 阶段签署”，任一不满足都不能锁定放行。
- 审计页提供完整的队列顺序记录（入队、重放、冲突、合并、放弃）。

## 技术栈

React、Fluent UI、Redux Toolkit、React Router、RTK Query、Vite、TypeScript。

## 运行

```bash
npm install
npm run dev
```

访问 `http://localhost:62061`。工卡草稿、提交队列、审计操作保存在 `localStorage`（键 `yy61-work-package`）；模拟服务器状态保存在 `yy61-mock-server`，清除该键可重置演示数据。

队列横幅中的“模拟他端已提交”按钮可制造服务器版本变化，用于演练冲突合并流程。

```bash
npm run build
```
