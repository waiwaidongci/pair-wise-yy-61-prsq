# pair-wise-yy-61 航空器定检工作包执行与放行审阅平台

支持工卡依赖、测量值容差校验、**可恢复的有序提交队列**、**双方保留的版本冲突合并**、分阶段签字、版本差异和放行锁定。超差项目必须由授权人员处理后才能继续。

## 离线提交与冲突处理

- 所有「完成并提交」先进入带编号的提交队列并持久化到 `localStorage`，页面关闭/刷新后仍可恢复。
- 在线时按编号 **FIFO 顺序重放**；离线时只暂存，恢复联网后先校验服务器版本再重放。
- 服务器上该工卡已有新版本时，**本地 patch 与服务器快照同时保留**，队列在该提交处挂起并阻断后续提交。
- 执行人员在冲突对话框中逐字段选择：采用本地、采用服务器或合并编辑；也可放弃本地版本（本地内容仅留档审计）。系统不会悄悄覆盖任何一方。
- 提交被服务器接收后，工卡内容、工作包版本、审计记录在同一事务内更新；放行门禁新增「提交队列全部重放、无未决冲突」检查项。

顶栏「离线暂存 / 恢复在线」可切换网络状态，离线时可用「模拟服务器端变更」演练网络中断期间其他终端修改同一工卡的场景。

## 技术栈

React、Fluent UI、Redux Toolkit、React Router、RTK Query、Vite、TypeScript。

## 运行

```bash
npm install
npm run dev
```

访问 `http://localhost:62061`。工卡草稿、提交队列和审计操作保存在 `localStorage`。

```bash
npm run build        # 类型检查 + 生产构建
npm run test:queue   # 提交队列端到端冒烟（FIFO / 冲突 / 合并 / 放弃 / 持久化 / 门禁）
```
